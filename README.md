# PERFECT GREEN

> 美しいものは、循環する。

**https://perfectgreen.net**

---

## このプロジェクトについて

PERFECT GREEN は、株式会社スバルグラフィックが立ち上げた、環境対応印刷の新ブランドです。脱炭素時代のZINEづくりを軸に、FSC認証、カーボンニュートラル、GHG排出ゼロを備えた印刷サービスを提供します。「環境対応」を訴えるのではなく、「美しさの条件として循環する」という思想で組み立てられたブランドです。

---

## サイト構成

- `index.html` — トップページ
- `paper.html` — paper Sample Book（紙ソムリエが選んだ14種の紙）
- `style.css` — 共通CSS
- `images/` — サイトで使用する画像ファイル
- `DESIGN.md` — デザインシステム（Elite Editorial）
- `CLAUDE.md` — Claude Code 用のプロジェクト記憶
- `SESSION_LOG.md` — セッションごとの作業記録

---

## 技術

- 静的サイト（HTML + CSS のみ、フレームワーク不使用）
- GitHub Pages によるホスティング
- カスタムドメイン: perfectgreen.net（HTTPS）

---

## 開発

**セットアップ:**

```bash
git clone https://github.com/sakai-creator/perfectgreen.git
cd perfectgreen
```

**ローカルプレビュー:**

```bash
open index.html
```

index.html をブラウザで直接開く。

**デプロイ:**

main ブランチに push すると、GitHub Pages が自動でデプロイ。

```bash
git add .
git commit -m "変更の説明"
git push
```
